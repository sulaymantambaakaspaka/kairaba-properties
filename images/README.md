# Kairaba Properties - Image Manifest

This is the **image manifest** for the site. The build ships with **placeholder photos** in this folder so every page renders out of the box. The tables below list each slot with its filename, dimensions, subject, and search keywords. **Replace the placeholders with your own royalty-free JPEG photos** from [Pexels](https://pexels.com) or [Unsplash](https://unsplash.com), saving them with the **same filenames** so they drop straight into the HTML with no path changes.

> UI icons (map-pin, phone, bed, bath, home, key, etc.) are **inline SVG** written directly in the HTML and coloured with `currentColor`. They are **not** files in this folder, and never emoji or an icon-font CDN.

Match the suggested dimensions as closely as possible (banners wider, cards roughly 800 x 600). The "keywords" column doubles as a Pexels / Unsplash search suggestion. Give every image descriptive `alt` text in the HTML.
